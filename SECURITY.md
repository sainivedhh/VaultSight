# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount to the VaultSight DSPM toolkit. If you identify a security vulnerability or potential exposure:

1. **Do Not Open a Public Issue**: Please refrain from opening publicly visible GitHub issues or pull requests.
2. **Contact**: Report details via email to `security-reports@vaultsight.local` or through GitHub's Private Vulnerability Reporting feature.
3. **Information to Include**:
   - Component affected (e.g. Detectors, Cloud Posture Checks, API, LLM Guard).
   - Clear reproduction steps or sample payload.
   - Perceived severity and impact on confidentiality, integrity, or availability.

## Responsible Disclosure & SLA
- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Remediation Timeline**: Within 14 days for Critical/High severity findings.
- **Credit**: We will credit researchers in release notes upon public disclosure.
